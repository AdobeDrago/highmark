Highmark EDS Migration

Tracking the migration of highmark.com to Adobe Edge Delivery Services (EDS), authored through Document Authoring (DA). This page summarizes what's live, recent work, and the block library available for building new pages.

What's live In progress

The home page and /resources section of highmark.com have been migrated to EDS. Additional pages and sections are being added incrementally as blocks and page templates are built out.

Preview Preview environment main--highmark--adobedrago.aem.page Latest authored content, pre-publish. Live Live environment main--highmark--adobedrago.aem.live Published, production-facing site. Author Document Authoring da.live/#/adobedrago/highmark Where content is authored and edited. Repo GitHub repository github.com/AdobeDrago/highmark Blocks, styles, scripts, and this docs page.
Status. Core page structure and the shared block library are in place. Styling variants (dark/minimal/light treatments, section color and centering options, a shop-specific card layout) are being layered on top as new page types are migrated.
